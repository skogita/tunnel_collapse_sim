# tunnel_collapse_sim
Mountain tunnel collapse simulator — bonded particles (DEM) and seepage, excavation and tunnel-face advance, CPU and GPU — with a Windows window app (Japanese and English screens) — design docs and code from the book Toward a Million Lines XIX / 山岳トンネルの崩壊のシミュレータと窓のアプリ（Windows・日英の画面）— 本『LLM で 100 万行のソフトウェア開発 XIX』の設計書とコード
